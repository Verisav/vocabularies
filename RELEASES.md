## Release historique mal étiquetée

La release GitHub **`1.1.2`** (23 janv. 2026) porte le titre **« Verisav Vocabularies v1.2.0 »** dans le corps de la release — le **tag** est `1.1.2`, pas `v1.2.0`. Elle documente l’introduction EU Business Wallet & Verifiable Credentials.

Pour éviter toute confusion : utiliser **`v1.5.2`** comme référence actuelle ; ne pas interpréter `1.1.2` comme la version des ontologies aujourd’hui.
