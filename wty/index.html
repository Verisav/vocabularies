Description

Le vocabulaire WTY/CNT (Warranty & Contracts) standardise les garanties et contrats sous un format machine-readable, permettant l'automatisation complète des décisions de paiement et évaluation de couverture dans le service après-vente.

Problème résolu : Aujourd'hui, les garanties sont des PDF illisibles de 40 pages. Avec ce vocabulaire, la question "Qui paie ?" est résolue automatiquement en < 1 seconde.

Classes principales

wty:Warranty

Garantie étendue qui définit couverture, exclusions, règles de paiement et conditions dans un format machine-readable.

Hérite de : dpp:Warranty, schema:WarrantyScope

wty:Contract

Contrat (maintenance, extension, assurance) qui définit termes et couverture pour le SAV.

Hérite de : schema:Contract

wty:Coverage

Définit ce qui est couvert par une garantie ou contrat (composants, types de défauts, types de réparations, périodes).

wty:Exclusion

Définit ce qui n'est PAS couvert (types de défauts exclus, causes exclues, composants exclus).

wty:PaymentRule

Règle de paiement définissant qui paie pour quoi (diagnostic, réparation, pièces, déplacement) et répartition entre parties.

Cœur de l'automatisation : Cette classe permet de déterminer automatiquement qui paie.

wty:Condition

Condition qui doit être remplie pour que la garantie/contrat s'applique (utilisation normale, installation correcte, documentation, preuves).

wty:Limit

Définit les limites (financières, temporelles, quantitatives) de couverture garantie/contrat.

wty:ClaimAssessment

Évaluation automatique d'une réclamation contre garantie/contrat, déterminant couverture et responsabilité de paiement.

Automation : Cette classe automatise la décision "couvert ou non couvert ?" et "qui paie ?".

wty:Invoice

Facture générée automatiquement basée sur règles de paiement garantie/contrat et évaluation de réclamation.

Hérite de : schema:Invoice

Flux d'automatisation

Ticket RMA → wty:triggersAssessment → wty:ClaimAssessment ├─ wty:checksCoverage → wty:Coverage ├─ wty:checksExclusions → wty:Exclusion └─ wty:determinesPayment → wty:PaymentRule ↓ wty:generatesInvoice → wty:Invoice

Exemple d'utilisation

Garantie constructeur 2 ans - Défaut de fabrication

:garantie1 a wty:Warranty ; dpp:warrantyType "constructeur" ; dpp:warrantyDurationMonths 24 ; wty:definesCoverage :couverture1 ; wty:definesPaymentRule :paiement1 . :couverture1 a wty:Coverage ; wty:coversDefectType "defaut_fabrication" ; wty:coveragePeriod "24_months" . :paiement1 a wty:PaymentRule ; wty:firstParty :fabricant ; wty:paysFor :reparation, :pieces, :deplacement ; wty:paymentPercentage 100.0 .

Résultat automatique : Fabricant paie 100% si défaut de fabrication

Intégration avec DPP et RMA

Le vocabulaire WTY s'intègre naturellement avec :

  • DPP : Utilise dpp:Warranty, dpp:ProductPassport, dpp:Intervention
  • RMA : Utilise rma:Ticket, rma:Dispute pour déclencher les évaluations
