# Changelog WTY

Toutes les évolutions notables du vocabulaire `wty` sont documentées ici.

## [1.1.0] - 2026-04-29

### Added
- Métadonnées de versioning officielles: `owl:versionIRI`, `dcterms:issued`.
- Distribution RDF/XML: `wty.xml`.
- Distribution checksum: `CHECKSUMS.sha256`.
- Artefacts de validation publiés: `validation/wty.shacl.ttl` et `validation/wty.schema.json`.

### Changed
- Mise à jour des distributions DCAT pour refléter tous les formats publiés.
- Mise à jour de la date de version dans l’ontologie (`dcterms:modified`).

### Breaking Changes
- Aucune.

## [1.0.0] - 2025-12-28

### Added
- Première publication stable du vocabulaire WTY/Contracts.

### Breaking Changes
- N/A (version initiale).
